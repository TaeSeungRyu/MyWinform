# WinFormsHello

C# WinForms 기반의 간단한 Windows 데스크톱 애플리케이션 연습 프로젝트입니다.

## 개발 환경

- Windows
- .NET 10 SDK
- Visual Studio Code

## 실행 방법

```bash
# .NET SDK 버전 확인
dotnet --version

# 프로젝트 실행
dotnet run
```

## 빌드

```bash
dotnet build
```

## 주요 기능

- WinForms 기반 GUI
- 버튼 클릭 이벤트 처리
- HTTP API 요청 및 응답 데이터 표시

## 참고

- Windows 환경에서만 실행 가능합니다.
- Visual Studio 없이 VS Code와 .NET CLI로 개발할 수 있습니다.
